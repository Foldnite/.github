# Foldnite — organisation workspace

This repository contains shared GitHub organisation materials, public contribution guidance, and the organisation profile displayed on GitHub. It is a place for reusable governance and navigation documents—not a substitute for the technical documentation in individual project repositories.

## About Foldnite

Foldnite explores **STEM-based interactive worlds**: science, technology, engineering, and mathematics presented through 3D environments, collaborative missions, simulation, and hands-on problem solving. The project may use separate runtime workstreams such as UNIGINE, UEFN, and Unity; they are not interchangeable deployment targets.

## Public contribution and rights

Do not submit secrets, credentials, personal data, customer-confidential information, or unapproved scientific data in public issues or pull requests. Contributions must have clear provenance and the contributor must have the right to submit them. Never upload code, assets, datasets, trademarks, or media without checking their licence and permitted use.
