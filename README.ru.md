# Foldnite — организационные материалы

Этот репозиторий содержит общие материалы GitHub-организации, правила публичного участия и профиль, отображаемый на GitHub. Это точка входа для навигации и повторно используемых правил, а не замена технической документации конкретных проектов.

## О Foldnite

Foldnite исследует **интерактивные STEM-миры**: науку, технологии, инженерию и математику через 3D-среды, совместные миссии, симуляцию и решение практических задач. В отдельных направлениях могут использоваться UNIGINE, UEFN и Unity; это разные runtime и разные пути публикации.

## Публичные материалы и права

Не размещайте в публичных issues и pull requests секреты, учётные данные, персональную информацию, конфиденциальные сведения клиентов или неразрешённые к публикации научные данные. Происхождение каждого вклада должно быть понятно, а автор обязан иметь право его предоставлять. Не загружайте код, ассеты, наборы данных, товарные знаки и медиа без проверки лицензии и разрешённого использования.

Материалы Foldnite, на которые организация имеет права, регулируются Restricted Proprietary License, если для конкретного компонента прямо не указана другая лицензия. Публичная видимость не означает разрешения копировать, распространять или коммерчески использовать такие материалы. Сторонние компоненты остаются под собственными условиями.
